GitHub Repository Health Analyzer is a web-based application that analyzes the health and activity of a GitHub repository. Users can enter a GitHub repository URL, and the application collects repository information using the GitHub API and calculates an overall health score based on important repository metrics.

The project is developed using HTML, CSS, and JavaScript for the frontend and Python Flask for the backend. The backend uses the GitHub API to retrieve repository data and provides an API endpoint for analyzing repositories. Flask-CORS is used to allow communication between the frontend and backend.

The application is deployed using Vercel for the frontend and Render for the backend. The project demonstrates API integration, frontend-backend communication, GitHub API usage, and deployment of a full-stack web application.
